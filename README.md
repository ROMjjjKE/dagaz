# ООО «Дагаз»: ремонт квартир под ключ, Витебск

Многостраничный сайт: чистый HTML, CSS и JS, без сборки и зависимостей.

## Страницы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Главная: что не придётся решать, обязанности подрядчика, схема этапов, работы, объекты |
| `remont-pod-klyuch.html` | Что значит «под ключ», пять блоков работ, новостройка против вторички, приёмка |
| `uslugi.html` | Все 20 видов работ по группам и логика порядка |
| `etapy.html` | Схема восьми этапов, кто заходит первым, контроль качества |
| `obekty.html` | Новостройка, вторичка, 1/2/3 комнаты, свободная планировка |
| `smeta.html` | Конструктор сметы: отметки работ, площадь, готовое сообщение в WhatsApp |
| `kontakty.html` | Телефон, WhatsApp, заявка |
| `politika.html` | Политика обработки данных |

## Сборка

```bash
python3 build.py
```

Шапка, меню, подвал и метаданные живут в одном шаблоне, поэтому правки не разъезжаются
между страницами. Текст правится в `build.py`.

## Что здесь настоящий интерактив

Конструктор сметы на `smeta.html` не считает деньги (тарифов у заказчика нет ни в брифе,
ни на сайте), он собирает задание: площадь, тип жилья, формат работ, отмеченные позиции
по пяти группам. На выходе готовое сообщение в WhatsApp. Схема этапов на главной и на
`etapy.html` показывает последовательность, а не календарь: длину полос сознательно не
подписывали днями, потому что сроки зависят от площади.

## Что заменить перед запуском

1. **Фотографии.** Все снимки в `assets/img/` сгенерированы как временные. Нужны реальные
   фото объектов: до и после, санузел, стяжка, плитка в процессе. Пропорции: главная 1:1.18,
   галерея 4:5, страницы разделов 16:7.
2. **Реквизиты.** В политике указан оператор без УНП и юридического адреса. Добавьте.
3. **Цены.** Если у компании есть прайс за м², его можно подставить в блоки работ: место
   под цену в вёрстке уже есть (в списках услуг и в конструкторе).
4. **Домен.** Сейчас `https://romjjjke.github.io/dagaz/`. Свой домен: Settings → Pages →
   Custom domain плюс файл `CNAME` и запись у регистратора.

## Проверки

- нет горизонтального скролла на 1440, 1280, 1120, 1024, 820, 768, 390 и 360 px
- контраст основного текста не ниже 5.6:1, кнопка на кобальте 9.2:1
- меню, конструктор сметы и форма проверены в браузере: валидация, сборка сообщения,
  возврат к правке списка
- `hidden` не перебивается CSS: меню и блоки результата скрыты до действия пользователя
- изображения с явными размерами, ленивая загрузка вне первого экрана
